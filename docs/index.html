Seven predictors, run as their authors released them. One vote.

metaLncRNA identifies long non-coding RNAs by majority vote of seven published coding-potential predictors. Each tool runs unmodified in its own container, pinned by digest, and decides with its own rule; metaLncRNA only counts the verdicts and records exactly what ran.

Why a consensus of originals

Predictors disagree, and the classics are hard to run as published.

Each coding-potential predictor was trained on different data with different features, so their calls differ on real transcripts. Several of the best known ones are Python 2 programs; rewriting them changes results, so a port is no longer the published tool.

01

The tools as published

CNCI, CPPred and LGC run from the authors' original archives, checked by SHA-256. CPAT, CPC2, PLEK and RNAsamba come from their Bioconda builds with the authors' own models.

02

One container per tool

Python 2.7, old LIBSVM builds and TensorFlow never meet. Every image is self-contained, pinned by digest and runs on Docker or Apptainer/Singularity.

03

Each tool decides

The consensus uses the label each tool itself outputs, with its own threshold. Scores are kept for inspection but never mixed or re-weighted.

04

Honest abstentions

A tool that cannot judge a transcript (too short for PLEK, an ambiguous base for CNCI, no CPAT model for plants) does not vote, instead of being guessed.

05

Provenance by default

provenance.json records the input hash, image digests, exact commands, run times and the reference of every tool that ran.

06

A small, plain wrapper

Python ≥ 3.11 standard library only. Checkpoints skip tools whose input, image and parameters did not change.

Method

From a FASTA file to one verdict per transcript.

metaLncRNA never touches a sequence and never interprets a score: it prepares the input, runs the seven containers and counts the votes.

Prepare

Transcripts get internal IDs, because the tools mangle names differently (CPAT upper-cases them). Sequences are not altered.

Run

Each predictor runs in its own container with its default parameters and the model chosen by --species.

Read

Each tool's own coding/noncoding label is parsed from its output; for CPAT, the authors' published species cut-off.

Vote

The majority of the tools that voted decides. Original IDs are restored in results.tsv and lncrna.fasta.

The rule

coding
more coding than noncoding votes
noncoding
more noncoding than coding votes
ambiguous
a tie among the tools that voted
unclassified
no tool voted
noncoding
ambiguous

Every tool counts once: no weights, no calibration, no stacking. agreement is the fraction of voters that side with the consensus.

When a tool abstains

PLEK
skips transcripts of 200 nt or less
CNCI
skips sequences that contain ambiguous bases
CPAT
has no model for plant or other
any tool
may fail; with --allow-failures the others still vote, otherwise the run stops

Abstentions appear as NA in results.tsv; the voters column says how many tools decided each transcript.

How to read this

  • The consensus scored above the median tool in every species and matched the best tool in mouse and fly; in human and zebrafish one tool alone did slightly better.
  • No single tool was best everywhere, and which one is best on your data is not known in advance.
  • Disagreement is common even on this easy set, which is why every tool's label is kept in results.tsv.

A consistency check, not a lncRNA benchmark. The ncRNAs in these sets are mostly short (median ≈ 110 nt; the human set is 95 snRNA and 5 rRNA; only 23 of 400 reach 200 nt), while the coding RNAs are mRNAs of 2–3 kb. They are CPPred's own held-out sets, and the other tools may have seen some of these transcripts in training. The numbers show that each container runs and is read correctly; they do not measure performance on long non-coding RNAs.

Install

A pip install and one setup command.

The wrapper has no Python dependencies; the seven public images are pulled from ghcr.io/labiomics by digest.

Requirements

  • Linux (x86-64)
  • Python 3.11 or newer
  • Docker, or Apptainer/Singularity on HPC clusters
  • Disk space for the images: CPAT and RNAsamba are the largest

The metalncrna releases 1.1.1–2.0.6 on PyPI belong to the previous, unrelated code base. Install 1.0.0 from GitHub.

# the wrapper
pip install git+https://github.com/LaBiOmicS/metaLncRNA@v1.0.0
# pull the seven images and verify them
metalncrna setup
metalncrna check

Each image is converted into a SIF file in ~/.cache/metalncrna (or $METALNCRNA_CACHE). The larger images need several GB of temporary space.

pip install git+https://github.com/LaBiOmicS/metaLncRNA@v1.0.0
# if /tmp is a small tmpfs
export APPTAINER_TMPDIR=$HOME/tmp
metalncrna setup --engine apptainer
metalncrna check --engine apptainer

Build the seven images from the Dockerfiles instead of pulling them. Upstream archives and model files are checked by SHA-256 during the build.

git clone https://github.com/LaBiOmicS/metaLncRNA
cd metaLncRNA
pip install .
metalncrna setup --build-from containers
Usage

One command per run.

Pick the species to select the CNCI, CPPred and CPAT models: human (default), mouse, fly, zebrafish, plant or other.

Human transcripts, all seven tools

metalncrna predict -i transcripts.fa -o results/

Plant transcripts (CPAT abstains)

metalncrna predict -i tx.fa -o res/ -s plant

Stronger support for lncRNA selection

metalncrna predict -i tx.fa -o res/ --min-agree 5

A subset of tools

metalncrna predict -i tx.fa -o res/ --tools cpc2,cpat,rnasamba

Keep going if a tool fails

metalncrna predict -i tx.fa -o res/ --allow-failures

More parallelism

metalncrna predict -i tx.fa -o res/ -j 7 -t 8

Outputs

results.tsv
one row per transcript: original ID, length, each tool's label and native score (NA = abstained), vote counts, consensus and agreement
lncrna.fasta
noncoding transcripts of at least --min-length nt (default 200), optionally with --min-agree noncoding votes, with their original headers
provenance.json
input SHA-256, image references and digests, exact commands, run times, per-tool status and citations
logs/
the complete output of each tool
Scope

What metaLncRNA does, and what it leaves to you.

It does

  • Run seven published predictors without changing their code, models or thresholds.
  • Combine their own labels by a transparent, unweighted majority vote.
  • Keep every tool's label and score, so you can apply a different rule yourself.
  • Record what ran, down to image digests and commands, for each result.

It does not

  • Retrain or tune any predictor, or add a model of its own.
  • Tell lncRNAs from other ncRNA classes: "noncoding" means no coding potential, and the length filter is the only lncRNA criterion.
  • Prove that a transcript is not translated; small ORFs and micropeptides need experimental evidence.
  • Assemble or quantify transcripts; it starts from a FASTA file of transcripts.
